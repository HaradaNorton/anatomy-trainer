# Тренажёр по анатомии

Тренажёр для подготовки к тестам по анатомии (стоматологический факультет).

Открыть: **https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/**

15 тестов, 300 вопросов. Режимы «Учить» и «Экзамен», разбор ошибок, печать ключа.
Прогресс сохраняется в браузере устройства.

Страница собирается скриптом `tools/build_portable.py` из основного проекта —
здесь лежит только готовый `index.html`.
